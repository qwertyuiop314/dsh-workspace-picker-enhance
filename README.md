# dsh-workspace-picker-enhance

> 独立的 DSH 插件：为“选择工作区”目录浏览面板增加跨盘符/挂载点浏览、面包屑一键跳转、无权限/系统目录视觉提示，并保留手动输入路径入口。

## 功能

- 打开目录浏览器时从 **“此电脑”**（Windows）或 **根目录 `/`**（Linux/macOS）开始，可自由进入各盘符/挂载点。
- 顶部 **“向上/返回上一级”** 按钮：在盘符根目录或 `/` 时点击返回盘符列表/挂载点列表。
- **面包屑导航**：动态展示完整路径，每一级可点击，点击立即跳转，无逐级动画。
- **手动输入模式**：点击标题栏“手动输入路径”图标切换；图形模式与手动模式共享当前路径，输入后可直接“浏览”或“选择此路径”。
- **风险目录视觉提示**：
  - 无读取权限目录：灰色 + 删除线 + 🔒，Tooltip 提示“无访问权限，不可选择”，点击被拦截并提示“无法访问此文件夹”。
  - 系统敏感目录：⚠️ 橙色警告图标，Tooltip 提示“系统目录，修改可能影响系统稳定性”。
  - “此电脑”及所有可用盘符/根目录始终可访问。
- 不修改 DSH 核心或原有 directory-picker-browse 插件源码；通过目录流插槽以更高优先级注入增强组件。卸载后原有面板恢复。

## 安装（仅限测试/沙盒环境）

> ⚠️ **交付红线**：请勿直接在生产环境或主程序安装。先在隔离沙盒、模拟环境或 DSH 测试实例中完整验证后再决定部署。

在 DSH 测试实例中，使用受保护的插件安装流程安装本目录（例如通过 DSH 插件管理器或 `dshpm install <本目录> --profile <name>`），安装后重启 DSH Web（bundle 插件需要重启生效）。卸载时使用对应的受保护移除流程。

## 验证清单

1. 图形界面从“此电脑”/根目录正常启动。
2. 跨盘符（C↔D）或挂载点切换流畅，路径正确回填。
3. 面包屑点击任意层级立即跳转。
4. 无权限目录显示删除线 + 🔒，点击被拦截并提示。
5. 系统目录显示 ⚠️ 警告。
6. 卸载插件后原有面板 100% 恢复原状。

## 结构

- `lib/index.js` — host 半部：`/plugins/workspace-picker-enhance/roots` 与 `/list` 路由，返回盘符/挂载点、权限、系统目录标记。
- `lib/client.js` — web client 半部：注册到 `conversation.hero.workspace.directoryFlow` 与 `sidebar.workspaces.directoryFlow` 插槽（priority -1）。
- `cordis.patch.yml` — bundle 补丁，仅插入本插件。
